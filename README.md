# Countdown Timer App

会議やプレゼンテーション、勉強会などで使える、シンプルなWebベースのカウントダウンタイマーです。

残り時間を大きな数字とプログレスバーで表示し、参加者や発表者が時間を把握しやすいように設計しています。

## 主な機能

- **カウントダウン**：設定した時間から秒単位でカウントダウン
- **時間設定**：30秒～30分まで、30秒単位で設定可能
- **スタート・ストップ・リセット**：タイマーの開始、一時停止、初期化
- **プログレスバー**：残り時間の割合を視覚的に表示
- **時間超過表示**：設定時間を過ぎると背景色が赤に変わり、超過時間をマイナス表示
- **催促表示**：「巻きで」ボタンで「巻きでお願いします」のメッセージと背景の点滅を表示
- **レスポンシブ対応**：PCやスマートフォンの画面サイズに合わせて表示を調整

## 使い方

1. `index.html` をWebブラウザで開きます。
2. 「時間設定」でカウントダウンする時間を選択します。
3. 「スタート」を押すとカウントダウンが始まります。
4. 必要に応じて「ストップ」で一時停止、「スタート」で再開できます。
5. 「リセット」で設定時間に戻せます。
6. 発表を早めてもらいたい場合は「巻きで」を押します。

設定時間を超過しても計測を続けるため、超過時間の確認にも利用できます。

## 利用シーン

- 会議の発言時間管理
- プレゼンテーションやLT（ライトニングトーク）
- 勉強会や研修
- イベントの進行管理
- 個人作業の時間管理
